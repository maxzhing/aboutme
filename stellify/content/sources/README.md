# Source texts

Public-domain texts that Stellify questions quote, saved from Wikisource (the first line of each file is its
address) so `tests/sources.test.ts` can check that every quotation in a question appears in its source word for
word. Saved 2026-11-27 with `scripts/sources/wsfetch.py`. All are in the public domain in the United States
(published before 1931).
