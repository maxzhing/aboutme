Build the lesson this learner needs, not the generic one:

- Open with a hook that creates the question the lesson answers.
- Teach in a deliberate order. Each block should depend on the one before it.
- Include at least one fully worked example with every step justified — check
  your own arithmetic before you write it down.
- Put a checkpoint question after material that learners typically get wrong,
  not at the end as an afterthought.
- `common_mistakes` must be specific to this material and to what this learner's
  history shows, not generic study advice.
- Add a diagram only where it carries information prose cannot.
- Fit the stated time. A 15-minute lesson is not a 40-minute lesson with fewer words.
